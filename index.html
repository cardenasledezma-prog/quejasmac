Despliegue en GitHub Pages y Firebase Cloud

1. Subir a GitHub Pages (con Logotipo ANM):

Suba este archivo renombrado como index.html a su repositorio y asegúrese de subir también la imagen del logotipo (image_d0ba41.jpg) en la misma carpeta raíz que index.html para que cargue en producción. Luego active Settings > Pages.

2. Configurar Firebase Cloud:

En console.firebase.google.com cree un proyecto, habilite Firestore Database y Firebase Storage, y copie su objeto firebaseConfig.

3. Intercambiar StorageService:

En el código fuente, active USE_FIREBASE = true dentro de StorageService para sincronizar todos los celulares en tiempo real.

Lineamientos de Redacción — Personal MAC

Estimado personal de Módulos de Atención Ciudadana (ANM), al redactar la descripción observe los siguientes lineamientos:

  • Objetividad y Claridad: Relate los hechos de forma imparcial, cronológica y precisa, evitando calificativos o juicios personales.
  • Respeto y Lenguaje Institucional: Mantenga un tono formal y respetuoso tanto hacia la ciudadanía como hacia el personal operativo.
  • Datos de Identificación del Evento: Indique fecha, hora aproximada, estación o ventanilla y folio de trámite relacionado.
  • Confidencialidad Estricta: Este escrito queda resguardado bajo folio único ANM y no será visible para terceros en esta terminal.
